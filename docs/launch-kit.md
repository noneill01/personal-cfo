# Personal CFO launch kit

These drafts are intentionally straightforward. Update version numbers and screenshots before posting.

## One-line description

Personal CFO is a private, local-first personal finance operating system that keeps your working financial data in your own browser instead of a hosted Personal CFO account.

## Reddit draft

**Title:** I built a local-first personal finance app that keeps the working data in your browser

I have been building **Personal CFO**, an open-source personal finance app focused on planning rather than just transaction history.

It tracks accounts, transactions, recurring commitments, pay cycles, Cash Runway, goals and Monthly Reviews. It also has an optional UK Tax evidence workspace.

The main design choice is privacy: the working financial database is kept locally in your browser. There is no Personal CFO account, hosted database, bank API connection or cloud sync service.

The latest version also includes a completely fictional demo profile, so you can explore the product before entering any real financial information.

Repository: https://github.com/noneill01/personal-cfo

It is still early and currently easiest to run on macOS with Node/pnpm. I would especially value feedback on onboarding, CSV imports, planning, and whether the product explains its calculations clearly.

Please use synthetic data in public bug reports or screenshots.

## Hacker News / Show HN draft

**Title:** Show HN: Personal CFO – a local-first personal finance operating system

Personal CFO is an open-source, local-first finance app that stores its working data in browser IndexedDB.

The goal is to go beyond expense tracking: pay-cycle planning, recurring commitments, Cash Runway, goals, Monthly Review and an optional UK Tax evidence workspace.

There is no hosted Personal CFO account, database, Open Banking connection or cloud sync. Backups are portable JSON files. A fictional demo profile lets you evaluate the app without entering personal data.

It is an early release and currently aimed at technical users comfortable running a local web app.

GitHub: https://github.com/noneill01/personal-cfo

I would be interested in feedback on the local-first architecture, onboarding friction, financial-model explainability and what would make this useful enough to keep using.
