# Personal CFO v0.1.1

## Focus

Make the first-run experience easier to evaluate and make the public repository easier to participate in.

## Highlights

- Add **Explore with demo data** to first-run onboarding.
- Load a completely fictional salary, accounts, spending, recurring commitments, planning data and emergency-fund goal.
- Clearly label the fictional profile while it is active.
- Add **Start with my data** to discard the demo and return to clean onboarding.
- Add public bug and feature-request templates with privacy guidance.
- Add a small launch kit for sharing the project without exposing private financial information.
- Keep UK Tax disabled in the demo by default.

## Upgrade notes

No migration is required. Existing users are unaffected. Demo mode is opt-in from the fresh-install welcome screen.

## Before publishing the release

- Run `pnpm test`.
- Run `pnpm lint`.
- Run `pnpm audit --prod`.
- Run `pnpm release:check`.
- Capture real app screenshots using only fictional demo data.
- Confirm the README reflects the final v0.1.1 experience.
